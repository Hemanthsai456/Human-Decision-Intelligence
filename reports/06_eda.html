Stage 06 — Exploratory Data Analysis

Hemanth Sai Charagundla

1. Purpose

This stage performs exploratory data analysis on the feature-enhanced CPC18 dataset.

The analysis examines decision behavior, expected payoff and probability differences, experimental conditions, temporal patterns, relationships among engineered features, and reaction-time data.

The purpose is to identify descriptive patterns that can guide the formal statistical analysis in Stage 07.

2. Prerequisites and Execution Order

Stage 06 depends on the validated and feature-enhanced CPC18 dataset.

The required execution order is:

  1. R/01_data_loading.R — load the CPC18 raw dataset.
  2. R/03_data_cleaning.R — create the cleaned analytical dataset.
  3. R/04_data_validation.R — validate logical and structural consistency.
  4. R/05_feature_engineering.R — construct mathematically meaningful decision features.
  5. R/06_eda.R — perform exploratory analysis.
  6. reports/06_eda.Rmd — document the exploratory findings.

The project root is explicitly set as the working directory before the pipeline scripts are sourced.

6. Experimental and Temporal Conditions

Choice behavior is explored across ambiguity and feedback conditions.

Temporal patterns are examined across time blocks and game order.

These analyses are descriptive and are used to identify relationships that may require formal testing.

9. EDA Summary

Stage 06 establishes the main descriptive patterns in the CPC18 decision data.

The observed relationships between decision attributes, experimental conditions, temporal variables, and choice behavior provide the basis for defining the formal statistical questions addressed in Stage 07.

No formal hypothesis-testing conclusions or causal interpretations are made at this stage.
